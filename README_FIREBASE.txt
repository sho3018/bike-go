バイクGO! — データを Firestore（クラウド）に保存する手順
================================================

Firestore は、Google の Firebase というサービスのデータベースです。
今までは投稿がこのパソコンの中の data.json に保存されていました。
Firestore にすると、投稿がインターネット上の Google の場所に保存されます。
無料の範囲ならお金はかかりません。カードの登録もいりません。

※ 鍵ファイル（serviceAccountKey.json）が入っていないときは、
　 今まで通り data.json に保存されます。だから、Firebase の準備が
　 まだでもサーバーは今まで通り使えます。

■ 準備するもの

・Google アカウント（Gmail のアカウント）
・インターネットにつながったパソコン

■ 手順1：Firebase のプロジェクトを作る

1. ブラウザで https://console.firebase.google.com を開く
2. Google アカウントでログインする（Gmail のアドレスとパスワード）
3. 「プロジェクトを追加」または「プロジェクトを作成」を押す
4. プロジェクト名に「bike-go」と入れて、「続行」を押す
5. 「このプロジェクトで Google アナリティクスを有効にする」が
　 出たら、チェックを外して「プロジェクトを作成」を押す
6. 「新しいプロジェクトの準備ができました」と出たら、
　 「続行」を押す

■ 手順2：Firestore のデータベースを作る

1. 左側のメニューで「構築」→「Firestore Database」を押す
　 （メニューが見えないときは、左上の三本線のマークを押す）
2. 「データベースを作成」を押す
3. 場所（ロケーション）は「asia-northeast1（東京）」を選ぶ
4. 「次へ」を押す
5. セキュリティルールは「テストモードで開始」を選んで、
　 「作成」を押す
6. 「firestore」と書かれた画面が出ればOK

■ 手順3：鍵ファイルを作って、フォルダに入れる

この鍵ファイルは、サーバーが Firestore に入るための合言葉です。
パスワードと同じくらい大事なファイルなので、人には渡さないでください。

1. 左上の歯車のマーク（設定）を押して、「プロジェクトの設定」を押す
2. 上のタブで「サービス アカウント」を押す
3. 「新しい秘密鍵の生成」を押す
4. 「キーを生成」を押すと、ファイルがダウンロードされる
5. ダウンロードしたファイルの名前を
　 「serviceAccountKey.json」に変える
　 （もともとの名前は「bike-go-○○○.json」みたいな名前です）
6. そのファイルを、「start.bat」と同じフォルダ
　 （bike-go-server フォルダ）の中に入れる

■ 手順4：サーバーを起動する

1. 「start.bat」をダブルクリックする
2. 初めてのときだけ、Firebase の部品のインストールが始まる
　 「First time setup: installing Firebase library. Please wait...」
　 と出て、1〜3分くらいかかる。終わるまで待つ
3. 黒い画面に「保存先: Firestore (bike-go)」と出れば成功
　 （「保存先: data.json」と出ていたら、手順3の鍵ファイルが
　 　フォルダに入っていないか、名前がちがう）
4. ブラウザで http://localhost:3000 を開く
5. デモアカウントでログインして、試しに1つ投稿してみる
　 メール： demo@bike-go.jp
　 パスワード： demo1234

■ 確認のしかた

・黒い画面を閉じて、もう1回「start.bat」をダブルクリックする。
　 さっきの投稿が残っていれば、保存は成功。
・Firebase の画面でも確認できる。
　 左側のメニューで「構築」→「Firestore Database」を開くと、
　 「users」「posts」「checklists」という箱ができていて、
　 その中に投稿やユーザーが入っている。

■ 今までのデータはどうなる？

初めて Firestore で起動したとき、data.json に残っていた投稿や
ユーザーが、自動で Firestore に移されます。だから今までの投稿は
消えません。移したあとは、data.json はもう使われません。

■ 絶対にやってはいけないこと

・serviceAccountKey.json を人に送らない
・serviceAccountKey.json をインターネットに上げない
・zip で誰かにサーバーを渡すときは、鍵ファイルを抜いてから渡す
　 （鍵が入ったままだと、誰でも翔のデータベースに入れてしまう）

もし鍵ファイルをなくしたり、誰かに見せてしまったら、
Firebase の「サービス アカウント」の画面でその鍵を削除して、
手順3からもう1回作り直してください。

■ 無料の範囲について

Firestore は、1日に読む回数が5万回まで、書く回数が2万回まで
無料です。卒研の発表やデモで使うくらいなら、まず超えません。
お金がかかる設定はしていないので、勝手に課金されることは
ありません。

■ 困ったとき

・黒い画面に「保存先: data.json」と出る
→ 鍵ファイルがフォルダに入っていないか、名前がちがいます。
　 ファイル名が「serviceAccountKey.json」になっているか、
　 「start.bat」と同じフォルダにあるか確認してください。

・「npm install failed」と出る
→ インターネットにつながっているか確認して、もう1回
　 「start.bat」をダブルクリックしてください。

・投稿すると「サーバーでエラーが起きました」と出る
→ 写真をファイルで入れた投稿は、写真が大きすぎると
　 Firestore に入りません（1つの投稿は1MBまで）。
　 そのときは、写真の URL を貼る方法で投稿してください。

・「firebase-admin が見つかりません」と出る
→ 初めての起動でインストールが終わっていないか、失敗しています。
　 黒い画面を閉じて、もう1回「start.bat」をダブルクリックしてください。
