バイクGO! サーバー版 — はじめに読んでね
========================================

これは、翔の卒業研究「バイクGO!」にサーバーをつけたものです。
前はブラウザを閉じると投稿が消えていましたが、
今は投稿・ユーザー・コメント・ヤエー・ブックマーク・点検記録が
保存されて、消えなくなります。

保存先は2つあります：
・serviceAccountKey.json があるとき → Firestore（クラウド）に保存
・ないとき → このフォルダの data.json に保存
Firestore にしたいときは「README_FIREBASE.txt」を見てください。

■ やることは、たったの2つ

Node.js をインストールする（1回だけ）
1. ブラウザで https://nodejs.org を開く
2. 「LTS」と書いてある緑のボタンを押してダウンロード
3. ダウンロードしたものを開いて、「次へ」を何回か押すだけ
4. インストールが終わったら、このフォルダに戻る

サーバーを起動する（毎回）
Windows の人：
「start.bat」をダブルクリック
Mac の人：
「start.command」をダブルクリック
※ もし開けないときは、「start.sh」を右クリック →
「ターミナルで開く」を選んでください

黒い画面が出て
「バイクGO! サーバーが起動しました」
と出ればOKです。この黒い画面は閉じないでください。

ブラウザで開く
ブラウザ（Chrome や Edge など）のアドレス欄に
http://localhost:3000
と入れて Enter を押してください。
バイクGO! が出てきます。

■ ログインしてみよう

デモアカウント（すぐ試せます）：
メール： demo@bike-go.jp
パスワード： demo1234

自分のアカウントを作りたいときは、
ログイン画面の「新規登録」タブから作れます。

■ サーバーを止めるとき

黒い画面を閉じるだけです。
データは data.json に残っているので、次に起動しても消えません。

■ 困ったとき

・「Node.js が見つかりません」と出る
→ Node.js のインストールがまだです。上の「Node.js をインストールする」の手順をやってください。
インストール後にパソコンを再起動すると直ることもあります。

・「このサイトにアクセスできません」と出る
→ 黒い画面が開いたままか確認してください。
黒い画面を閉じるとサーバーが止まります。
アドレスが http://localhost:3000 になっているかも確認してください。

・「ポートが使われています」と出る
→ サーバーが2つ起動しています。黒い画面を1つ閉じてください。

■ 中身の説明（先生に聞かれたとき用）

server.js
サーバーの本体です。serviceAccountKey.json があるときは
Firestore に、ないときは data.json にデータを保存します。
package.json
Firestore を使うための部品（firebase-admin）の名前が
書いてあります。初回起動時に start.bat が自動で入れます。
public/go_bike_go.html
画面のファイルです。投稿ボタンなどを押すと、サーバーに
データを送るようになっています。
data.json
鍵ファイルがないときのデータの保存場所です。投稿やユーザーが
ここに入ります。消すとデータが全部消えるので、バックアップを
取りたいときはこのファイルをコピーしてください。
serviceAccountKey.json（自分で入れるファイル）
Firestore に入るための鍵ファイルです。最初は入っていません。
作り方は「README_FIREBASE.txt」を見てください。
人に渡してはいけません。
start.bat / start.command
サーバーを起動するためのファイルです。鍵ファイルがあるときは
初回だけ部品のインストールをしてから起動します。

■ 注意

・これは卒業研究のデモ用のサーバーです。
本物のパスワードは使わないでください。
・このままインターネットに公開する作りにはなっていません。
自分のパソコンの中で使うか、発表のときだけ使うのがおすすめです。
同じWi-Fiの人に見せたいときは、先生に相談してください。

■ 仕組み（ざっくり）

ブラウザ ←→ サーバー(server.js) ←→ Firestore または data.json
・ログイン：メールとパスワードをサーバーが確認します
・投稿：サーバーが受け取って Firestore か data.json に書き込みます
・表示：ブラウザがサーバーから最新の投稿を取ってきます
Firestore のとき、データは users / posts / checklists という
3つの箱に分けて保存されます。

■ 遠くの人に見せたいとき

  一時的に見せるとき：
  「start-tunnel.bat」と「README_TUNNEL.txt」を見てください。
  トンネルを使うと、インターネットから開けるURLが出ます。

  ずっと公開したいとき（ホスティング）：
  「README_RENDER.txt」を見てください。
  Render というサービスにのせると、パソコンを閉じていても
  いつでもサイトが開けるようになります。
  その前に、Firestore の鍵（README_FIREBASE.txt）が必要です。
